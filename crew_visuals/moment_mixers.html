Choose the wires by their moments

To recover from five lost reports, every report needs at least six wires. Here is a rotating board that reaches six, built by making five consecutive power sums vanish. A second board tolerates six losses on seven wires. Try the moments to see the missing modes.

Each moment adds the values in the last column and takes the remainder. A zero means that mode is invisible to the mixer.

These boards have exactly r invisible modes in one consecutive run. They give an ambiguity described by a polynomial of degree below r. Any r distinct direct inputs sample it at distinct addresses, which determine it. Reversing the circle swaps inputs and reports, so removing any r reports leaves exactly that same ambiguity.

Make the moments vanish by design

We first look for d addresses u1, …, ud with power sums Sj = ∑ uij. Let E(t) = ∏(1 + uit). Its logarithmic derivative has coefficients S1 − S2t + S3t² − ⋯. To make the terms from degree 2 through d vanish, we want E′(t) = (1 − bt)E(t) through degree d.

Write the coefficients of E as hj/j!. Start with h0 = h1 = 1 and use hj+1 = hj − jbhj−1. Choose b so hd+1 = 0. Then solve for the ui using the elementary coefficients of the monic polynomial ∏(X − ui). We use b = 2,534 for the six wires and b = 120,498 for the seven. In these fields the addresses are distinct and nonzero.

Divide all the addresses by one of them so the first wire has offset zero. This only rescales each moment, so it preserves the zeros. Since 2 generates the nonzero residues in both fields, every address is a unique power of 2 and gives an offset. For an input sequence xi = zi, report i equals zi times the sum of zk over the offsets k. At mode z = 2j that sum is precisely the displayed power sum, so a zero makes the whole sequence invisible.

Why the number of wires is optimal

Any r direct coordinates of an invisible change are independent. A report with at most r wires would impose an equation among those same coordinates. So every report needs at least r + 1 wires. Marlow’s quartic mixer note gives a much smaller five-loss board with seven wires per report and a second six-wire construction from a different exponential series.
