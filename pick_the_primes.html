Why the routes give the determinant

Read the binary digits from left to right. The leading 1 starts one route. Each next digit doubles the route count. A digit of 1 adds a route that comes along a separate track. The first route has length one. Each doubling adds two steps, and a reused add-one path enters after three steps. Every route to the end therefore has odd length.

Reusing the add-one route removes the need for a new carry track at each digit. The compact version adds three vertices and four or five arrows per digit. Its number of ones grows only as fast as the number of digits.

Order the vertices so the arrows point forward. Mark one square for each arrow and one on every diagonal. This gives the triangular matrix I + N, where N records the arrows and the diagonal ones keep this block invertible in every field. Add a new row that selects the start and a new column that selects the end. The determinant of the bordered table is the negative start-to-end entry of (I + N)⁻¹.

The inverse is the finite series I − N + N² − N³ + ···. Its start-to-end entry counts routes with alternating signs by length. Every route here has odd length, so the negative of that entry is the number entered. The triangular block guarantees that the rank can drop by only one.
