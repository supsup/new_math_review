How the comparison was checked

In each column, the number at the top is its weight. Add those weights wherever the row has a 1. Every sum above the last row is zero from the start. The last sum is −17, which also vanishes when we switch arithmetic.

Both determinants have magnitude 17, so each matrix loses exactly one rank there. The exhaustive seven-row scan found a minimum of 24 ones at that size. To rule out 22 in a larger board, expand away any row or column containing just one 1. A remaining board with at least two ones in each row can have at most eleven rows.
