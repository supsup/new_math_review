More twos, fewer missing directions

The Fano board has determinant magnitude 24. Erasing one 1 makes it 16, which contains more factors of 2. Yet the edited board loses fewer independent directions modulo 2. Change the modulus to see where the extra factors go.

Read the two numbers in each square

The large number is a coefficient in a simplified equation dx = 0. The small number counts the residues that solve that equation in the selected arithmetic. For example, when d = 8 and the modulus is 4, every residue works.

Integer row and column operations with integer inverses turn each board into a diagonal matrix. Those operations are reversible in every modulus. The diagonal is the Smith normal form. It can be found from the greatest common divisors of successively larger minors, which this page computes exactly.

The number of choices for a single new variable is gcd(d, modulus). Multiply the seven counts because the equations have separate variables. Modulo 2, an even coefficient leaves a free variable and an odd one forces zero. A large power of 2 in one coefficient can therefore add many choices modulo 8 even if there are fewer free variables modulo 2.
