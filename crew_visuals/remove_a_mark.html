    Where the rank comes from

    Imagine one matrix column per starting set and one row per possible set left over. Put a 1 where the row is a subset of the column. Adding your selected columns modulo 2 produces the output shown above.

    If the rank is r, r independent columns can be turned on or off to give 2r distinct outputs. This page counts those outputs and works backward to find the rank.
