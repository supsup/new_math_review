How the field and the prediction work

In a field with 5n elements, use n digits from 0 to 4 as coefficients of a polynomial in z. Add and multiply coefficients modulo 5, then replace powers of z using an irreducible polynomial of degree n. Here the relations are z² = 2, z³ = −z − 1, and z⁴ = −2 for n = 2, 3, 4.

The first count gives the trace 5 + 1 − 8 = −2. The roots of T² + 2T + 5 are −1 + 2i and −1 − 2i. In a field of size 5n, the trace is the sum of their nth powers, twice the real part shown. Subtract that trace from 5n + 1 for the point count.

Each power has modulus √(5n), so the picture divides by that radius to put both on the same circle each time. Twice the horizontal component before dividing is the trace, and its absolute value is bounded by twice the radius. This is the curve version of the Riemann Hypothesis.
