Width is the number of terms in the longest rule. In 3-SAT, the problem behind these ETH results, each rule has at most three terms. Try six zeros to see when sharing a check costs more.

When does sharing pay off?

For each selected position, a separate check pays for reducing the width of every value-bit rule. A shared lookup pays once for each group of index bits it tests. The shared cost stays fixed when values need more bits.

How the counts are checked

Each formula chooses three array positions in increasing order and adds the values in signed binary. A position uniquely determines its value. Every added variable is pinned down by the inputs to a Boolean gate.

The page evaluates all combinations of index bits in each formula, including unused index codes. It propagates the clauses and checks that each surviving triple has exactly one full assignment. Then it compares the triples against direct enumeration.

The three encodings were built for this page. They connect the integer 3SUM problem of Alman and Vassilevska Williams with the counting-SAT statements from OpenAI and Anthropic.
