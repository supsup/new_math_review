Two questions. Two answers.
“Does a satisfying assignment exist?” is Boolean. “How much weight do all satisfying assignments carry?” is arithmetic. Zero-weight assignments contribute nothing to the second answer and still matter to the first.
A hard pin is different: it removes assignments that disagree. Try pinning two adjacent variables true. Both clouds then lose every model, and the SAT indicator changes.
Each thin line connects two valid assignments differing in one variable. Positions are a fixed embedding of bitstrings, not a distance or cluster theorem. The right pane scales dot size relative to its largest weight; the displayed sum remains exact.
A small exact-counting engine.
The example formula forbids true–true pairs between neighboring blocks. The solver finds exact identical-neighborhood groups, verifies every edge, constructs a cycle-breaking set and counts the resulting forests.
time ≤ poly(L) · 2ʳ
r = quotient edges − groups + components
For this restricted family, logarithmic cycle rank gives polynomial time, including recognition. This visual deliberately stops at 12 original variables so it can independently enumerate every assignment; it is a finite check, not a complexity benchmark.
