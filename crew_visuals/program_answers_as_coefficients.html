How a polynomial stores a program’s answers

Give each possible input word its own term. Put the answer for that input in the term’s coefficient. A row of zeroes and ones can then select any one answer. Both VP versus VNP papers use polynomials of this form in their proofs.

Use one pair of variables for each bit

The word 1011 has term x₁,₁ x₂,₀ x₃,₁ x₄,₁. Put a 1 in the chosen slot at each position and a 0 in the other slot. The chosen product becomes 1. Every other word disagrees at some position and picks up a 0.

The toy program chooses an even number of positions whose bits are 1. For 1011 it can choose none, or choose one of the three pairs. The coefficient is 4. At each input bit, the program can keep its parity. At a 1 it can also switch parity. The coefficient counts the paths ending in the even state.

Many coefficients can still come from a small circuit

Keep two running polynomials, one for even parity and one for odd. Start with 1 and 0. At each position, multiply both states by xi,0 + xi,1 to account for keeping parity, and add xi,1 times the opposite state to account for switching. This uses a fixed number of gates per bit. The final even polynomial still has exponentially many coefficients. Exact path-count replay.

Where this idea enters the two proofs

The OpenAI paper uses a universal machine, with a program encoded in a prefix of the word. Its coefficient counts accepting paths within a time limit. The Anthropic paper uses weighted runs of a universal automaton. The same pattern of one variable per position and symbol lets a setting of zeroes and ones read one coefficient. Both proofs ask what happens when tensor networks can send bits using less wire than a straight geometric comparison suggests. A wire here is a shared index, and the price measures how expensive it is to coordinate tables of values.

A geometric lower bound

OpenAI’s route without strict shortening uses low-rank pieces across balanced cuts. Pieces that save enough rank would also save wire. Anthropic’s flat case uses Euclidean prices to turn a balanced decomposition of a complete-graph wire polynomial into a gate lower bound.

A program that replays a circuit

In OpenAI’s shortening case and Anthropic’s contracting case, savings make it possible to simulate a hypothetical small circuit inside the universal computation. The proof arranges a program that changes the value the circuit would give to that program’s own coefficient.

This last step needs the circuit replay to fit the available time or wire budget. The papers build that economy using the internal low-degree computations of the circuit.
