Why the torsion points form a grid

Identify opposite edges of a square to make a torus. Pick a dot in each square, then multiply by n. The point returns to the origin in every square. The grid shows all the points that return, and changing the dimension shows why their count is n2g.

Two coordinates per square

In each square, moving by an integer in either direction brings you back to the same point. So n times is the integer pair which is the origin on the torus. Conversely, if multiplication by n reaches the origin, both coordinates were integer multiples of 1/n.

Choose a and b independently from 0 through n − 1. Each square has n² choices, and there are g independent squares. The single-square model is ℂ/(ℤ + iℤ). For a complex torus of dimension g, a lattice basis gives the same count using 2g real coordinates.

What the archive proves

The same count holds for a g-dimensional abelian scheme over an algebraically closed field, whenever n is nonzero in that field. In positive characteristic, this means n is prime to the characteristic. The statement counts the points killed by n, including the identity. Milne, Abelian Varieties, Theorem 8.2.
