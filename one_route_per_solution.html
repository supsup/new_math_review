Why the determinant counts the routes

Use nine vertices. One is the start, four are row choices, and four are column choices. Give each row and column vertex a loop back to itself. Draw arrows from the start to each row and from each column back to the start. An entry of 1 adds the arrow from that row to that column.

Every nonzero determinant term must choose one way for the start to leave and come back. The only possible cycle through the start uses one solution arrow. It has length three, which gives a plus sign. Every unused vertex takes its loop. So the sum of the determinant terms is exactly the number of solutions.

The eight-by-eight block away from the start is triangular with ones along its diagonal, so those eight rows remain independent in any field.
