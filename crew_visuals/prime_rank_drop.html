When a prime changes the rank

A board of zeros and ones can have independent columns over the fractions. Then a prime makes one column combination vanish. Follow the same column weights across the rows to see where that happens.

Why these are the smallest boards

Each displayed determinant equals the chosen prime up to sign. The rows above the last row stay independent modulo that prime. This gives the exact ranks shown above.

A matrix loses rank modulo a prime if that prime divides every minor of maximal ordinary rank. The absolute determinant bounds below imply that the first possible square board for each prime must have full ordinary rank. Once the size is fixed, we ask how few ones it can use.

At the first possible size a row with just one 1 would reduce the question to a smaller determinant by expansion, so every row needs at least two. That gives six ones for the prime 2. For the prime 3, rows with two ones ask two weights to be opposites. An even cycle lets one weight vary and an odd cycle forces it to zero. This works both over the fractions and modulo 3, so a board made entirely of those rows cannot change rank. A heavier row raises the minimum to nine.

For the size bounds, the maximum absolute determinants through size four are 1, 1, 2 and 3 by direct enumeration. At size five, bordering into a sign matrix and applying Hadamard bounds the determinant by 6³/2⁵ < 7. For size six the maximum is 9. Williamson on binary determinant maxima
