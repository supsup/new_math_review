Runtime Zoom Tunnel (card 378)

STATEMENT READ; CHECKER NOT RUN. The formalized (log log n)^2 / sqrt(log n) route only.

The Lean statement bounds the running time by B(n, L) = C (L+1)^d 2^(A n f(n)), with f(n) = (ln ln(n+16))^2 / sqrt(ln(n+16)), natural logarithms and the +16 exactly as in the Lean's runtimeScale(n) = n f(n). One zoom control moves n from 0 to astronomically large sizes. The left instrument shows the coefficient A f(n) against 1; the right instrument shows the number of bits in the whole illustrative bound, log2 B, against n, the number of bits in 2^n. The coefficient rises, peaks and falls; the bound keeps growing the whole time. A falling coefficient is not a falling runtime.

Illustrative throughout: the theorem gives C, A and d only existentially, so every value below is an example, not a witness extracted from the theorem, and L(n) is a hypothetical input-length model. A point below the 2^n reference means only that this illustrative upper bound is below 2^n there, not an observed speedup.
