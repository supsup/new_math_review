The A threshold: where the exponent term alone exceeds 2^n (family 378)

With f(n) = (ln ln(n+16))^2 / sqrt(ln(n+16)) exactly as runtimeScale n = n f(n) defines it, the exponent term 2^(A n f(n)) exceeds 2^n exactly where A > 1/f(n). The curve A = 1/f(n) is lowest at the peak of f, so the exponent term is strictly below 2^n at every real n > 0 exactly when A < e^2/16 = 0.46181600618... (Confluence's threshold; n = 0 is excluded, where both are 1). At A = e^2/16 the strict-exceedance band is empty; the exponent term only touches 2^n (a tangency) at the real peak point, which is not an integer. Above it, one band opens and closes; the slider shows its two edges.

Illustrative; the theorem gives only C, A, d existentially. Exponent component on the map; the panel adds C, d and L (the challenge's unary input length, about 51 n^2 for a random 3-CNF) for log2 C + d log2(L+1) <= n (1 - A f(n)).
