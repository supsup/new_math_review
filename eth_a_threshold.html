The A threshold: where the exponent term alone exceeds 2^n (family 378)

With f(n) = (ln ln(n+16))^2 / sqrt(ln(n+16)) exactly as runtimeScale n = n f(n) defines it, the exponent term 2^(A n f(n)) exceeds 2^n exactly where A > 1/f(n). The curve A = 1/f(n) is lowest at the peak of f, so the exponent term is below 2^n at every real n >= 0 exactly when A < e^2/16 = 0.46181600618... (Confluence's threshold; at A = e^2/16 it only touches 2^n, at the real peak point, which is not an integer). Above it, one band opens and closes; the slider shows its two edges.
