THE METHOD

What makes the count exact?

01 / COMPRESS

Equal neighbors,
one class.

Compare complete sorted open-neighborhood tuples, not degrees. Each class is independent. Cross-class edges are complete or absent; we verify the original edge set is covered exactly.

aᵢ = ∏ wᵥ(0)
bᵢ = ∏ [wᵥ(0) + wᵥ(1)] − aᵢ

Empty weight aᵢ; nonempty weight bᵢ. With unit weights: aᵢ = 1 and bᵢ = 2|class| − 1.

02 / CUT

Hit every
non-tree edge.

Build a spanning forest of the quotient H. For each remaining edge choose its lower-numbered endpoint for S. Deleting S leaves only forest edges.

r = |E(H)| − |V(H)| + components(H)
|S| ≤ r

This constructs a sufficient cutset. It does not solve minimum feedback vertex set.

03 / SUM

Two states
per forest vertex.

Reject adjacent occupied cutset classes. An occupied cutset class forces every forest neighbor empty. For each remaining tree, work from leaves to root.

Eᵢ = aᵢ ∏ (Eⱼ + Nⱼ)
Nᵢ = bᵢ ∏ Eⱼ

Set Nᵢ = 0 when forced empty. Multiply root sums and the branch factor; then add disjoint branch contributions.

THE CLAIM BOUNDARY

Structure is a promise.
Not a universal shortcut.

The method has structural work bound O(2ʳ poly(L)). It is polynomial for fixed r, or for r ≤ c log₂ L with a fixed constant c. Unrestricted r can still be large. BigInt arithmetic is exact; it is not free.

Here L is the length of our original labeled graph encoding: unary n and m headers plus fixed-width edge endpoints. The quotient is never substituted for L, free variables are never discarded, and no padding is added to satisfy a threshold. This page is a finite educational implementation of an elementary proof sketch, not a formal proof or a runtime benchmark.

All-negative binary CNF always has the all-zero Boolean model. In zero-weight mode that model has weight zero: Z = 0 does not mean UNSAT. The Boolean model count remains a separate quantity.
